# 能量頁調整

「看見起伏」只負責能量評分和月內排序。移除獨立「觀察／寫下觀察」區塊、對應表單和入口，沒有把另一個必填步驟加回流程。

## 操作

- 事件按月份分組；同月內拖曳六點圖示排序。桌面橫向排列，窄螢幕直向排列。
- 拖曳只改變該月的順序，不移動月份。放開時寫入一次，年度曲線與逐月卡片使用同一份順序。
- 也可點卡片上的前後箭頭；聚焦拖曳圖示後，可用方向鍵、Home、End 排序。Escape、觸控中斷或放到月份外都取消，不寫入預覽。
- 卡片其他區域保持可捲動；只在拖曳圖示上使用 touch-action: none。拖曳接近視窗上下緣時支援捲動。
- 評分視窗的事件摘要完全唯讀，不再有 1／2／3 順序欄位。只提供能量、未評分和明確的 0 分操作。
- 本頁不顯示或填寫情緒、感受、回應空間、重要性；發生方式沿用事件階段的唯讀標記。日常背景不參與月內排序或年度連線。
- 練習新增第二張六月事件，讓使用者能實際練習排序。示範仍使用隔離的記憶體副本。

## 相容性

不更換 LocalStorage 鍵，也不變更 v1 備份結構。移除介面不會刪除既有觀察、情緒、感受、私密標記或其他事件欄位。評分表單未出現的欄位沿用原值；JSON 匯入、匯出仍保留舊資料。儲存配額不足或跨分頁衝突時沿用既有保護，不會以新順序覆寫外部分頁。

先前要求的「卡片分群／詞語連結」文字也納入此版，並讓「發現線索」的提示對應目前模式，直接交代選卡、命名與儲存動作。

## 驗證

```sh
npm run check
npm run build
python tests/energy-board.py
python tests/rating.py
python tests/flows.py
python tests/guide.py
python tests/smoke.py
```

單元測試包含插入排序、前後移動、無變動、空缺順序、不合法位置、背景卡、欄位與舊備份保留。介面測試包含滑鼠拖曳、Chromium CDP 觸控輸入、鍵盤和點擊替代操作、取消、月份外放開、SVG 更新、讀回順序、私密遮蔽、舊欄位保留、儲存失敗與示範隔離。

瀏覽器測試使用建置後的本機 HTML 和明確的 Storage 替身。這驗證序列化與介面行為，不代表已在公開網站、原生跨分頁儲存或實體 iPhone Safari 完成測試。
