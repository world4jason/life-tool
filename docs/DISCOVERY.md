# 發現線索：二分類與分群

本版改動以 `d58e751` 為基礎，不合併另一個原型分支。

## 操作

「二分類」輸入詞語，用有關／無關逐張判斷全部事件（含日常背景）。未操作的卡維持未判斷，不推定為無關。可跳到其他待判斷卡、改判、退回未判斷、復原，或用拖曳代替按鈕。每個詞保留獨立分類；負能量事件可以與詞有關。介面顯示有關、無關、未判斷的張數，不以涵蓋數自動選目標。

「分群」勾選事件建立群組，或拖曳到新增群組區；成群後命名。拖曳或移動選單可換群，移動選單另提供保留原群的加入方式。同一事件可以出現在不同群。未入群不代表無關。群組文字只要求名稱，不再同時詢問價值、反例或未來方向。既有反例等文字仍保留在資料中。

提示依選詞、分類、成群、命名和完成狀態變更。個人頁的「操作示範」直接進入本關同一模式的隔離練習；分群示範指出可操作的兩張卡。所有示範修改只在記憶體，退出恢復原工作區及未提交的命名草稿。

網址 `?guide=1&step=3` 進入二分類練習；`?guide=1&step=3&method=group` 進入分群練習。一般頁面操作不必先進示範。

## 與後續流程連結

分類結果保留 theme ID。點「帶到下一步」或「比較做法」到「打開可能」，在該頁確認想保留或改變的方向。新詞的 `value` 和 `intention` 不自動填成詞語。修改名稱、分類、方向不改寫既有 route、node、review。路線、OKR、多層計畫、驗收機制沿用。

未命名群組不能透過群組的下一步按鈕被選為方向。允許尚有未判斷／未分群事件就繼續，沒有強迫完成百分比。

## 資料相容

資料格式升為 version 2，工作區 storage key 保持不變以讀取原紀錄。每個 theme 新增：

- `method`: binary / group / legacy。
- `unrelatedEventIds`: 僅二分類使用的明確無關事件 ID。
- `eventIds`: 延續原欄位，代表相關事件或群內事件。

v1 讀取時轉為 legacy，保留全部已知欄位、事件、路線、計畫和回顧；沒有勾選的事件不推定為無關。原主題在分群模式繼續操作，不猜測它是如何建立的。首次寫入 v2 前保存原字串到 `<workspace-key>.before-v2`，失敗則保留原儲存內容並顯示未儲存。v2 備份不相容舊版網頁，其他舊分頁請重新整理。

驗證禁止有關／無關重疊、重複 ID、懸空關聯及分群帶入無關清單。刪除事件會清除兩份關聯；刪除詞語保留既有路線及行動，清除它們對該詞的 ID 關聯。復原只適用同一狀態修訂，不跨越其他計畫編輯。

## 驗證

`npm run check`、`npm run build`、`python tests/discovery.py`。其他既有瀏覽器回歸：`flows.py`、`guide.py`、`rating.py`、`energy-board.py`、`smoke.py`。

本機以 Chromium 載入精確單檔產物及明確的 Storage shim。觸控使用 Chromium CDP 模擬；這不是實機 iOS Safari 測試。實際嘗試本機 HTTP 導航回傳 `ERR_BLOCKED_BY_ADMINISTRATOR`，沒有繞過管理政策；因此不宣稱原生 HTTP 持久化驗證完成。

單檔建置保留各模組獨立作用域；沒有外部 CDN、字型或追蹤請求。JSON 備份含私密文字且未加密。
