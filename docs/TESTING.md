# 驗證範圍

## 本次本機執行結果

2026-09-08，Node.js 22.16.0、Python Playwright 1.57.0、容器內 Chromium。

- `npm test`：21 項單元測試通過。
- `npm run build`：靜態網站與單檔 HTML 建置成功。
- `TEST_MODE=document python tests/e2e.py`：20 組瀏覽器情境通過；無 pageerror、無外部網路請求。
- 320、360、390、768、1440 px：全部七個頁面與實驗表單沒有整頁水平溢位。能量曲線在窄螢幕內部橫向捲動是刻意設計。

**限制：** 此容器的 Chromium 導航被管理政策封鎖，localhost 與 file URL 都無法直接開啟。因此本次瀏覽器測試使用 `set_content` 注入產生的單檔 HTML；一般儲存情境使用明確的 Storage 測試替身，重載與多分頁事件以重播／合成方式驗證。儲存被拒時的警告與備份流程也有測試。這些結果不代表已驗證真實 HTTP、file:// 持久化、iPhone Safari、Android 實機或 Firefox。

CI 的預設瀏覽器模式是 HTTP，會使用真正的本機伺服器與 LocalStorage。是否已完成 CI，應以 GitHub 該次執行結果為準，不以本文件推定。

`test-results/` 是本機產物，不提交到 repository。測試資料全部為虛構，不要用個人年度備份作為測試 fixture 或 CI artifact。
