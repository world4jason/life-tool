# 示範引導與文案調整

本次是既有 main（`cd5ea6b`）的增量修改。不合併另一套原型，不修改 v1 資料格式或既有儲存鍵。

首頁「跟著示範做」與頂部「操作引導」開啟六步練習；`?guide=1` 可以直接進入。每步只有一段操作提示、實際表單入口、上一步／下一步。可跳過、返回或離開，不以分數或是否填完判定通過。

範例由旅行、活動安排與留白的事件，連到主題、三條候選路線、行動驗收與回顧。選擇短旅行或先觀察時，第一次產生的實驗會對應所選路線。已修改的實驗不會因返回前一步而被覆寫。「已練習」只在提交對應表單後出現；跳到後面的步驟只提供範例，不算完成。

示範使用記憶體副本。開始時暫存原本的 state、選取狀態及儲存警告；退出後還原，包括尚未成功寫入本機的修改。整輪練習不寫入個人或舊示範桌的 LocalStorage，重新整理會清除練習。回到個人桌時再次檢查另一個分頁有沒有變更，避免覆寫。備份／匯入／重設／年度設定在練習中不開放，以免混用資料。

介面移除英文裝飾小標、側欄副標、框架講解及重複鼓勵語；保留欄位標籤、資源單位、私密／備份／刪除等必要提醒。導覽期間不再重複顯示各頁的一般操作提示。評分的靜態事件摘要、可調順序及單選發生方式標籤維持不變。

## 開發與驗證

```sh
npm run check
npm run build
python tests/guide.py
python tests/flows.py
python tests/smoke.py
```

本次本機驗證：52 個單元測試（既有 40 個＋引導 12 個）、22 個引導互動檢查、27 個既有流程檢查通過。引導檢查包括 5 種寬度 × 6 步驟／表單（30 組），既有 smoke 包括 5 種寬度 × 7 頁（35 組）。兩者不應加總宣稱為獨立裝置數。

容器內 Chromium 的 HTTP 導航被管理政策阻擋（`ERR_BLOCKED_BY_ADMINISTRATOR`），因此瀏覽器測試讀取建置出的單檔 HTML，使用明確的 Storage 測試替身。這些結果不是原生來源持久儲存、公開站點載入或真實手機 Safari 的驗證。公開部署狀態另由 GitHub Actions 確認。

`src/guide.mjs` 管理虛構教材與延後建立的實驗；`src/app.mjs` 管理引導、記憶體隔離、實際表單與恢復；`src/guide.css` 提供桌面與手機版面。建置包含同一組模組和 CSS，沒有第三方服務或新增追蹤。
